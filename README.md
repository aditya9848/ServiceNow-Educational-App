# 🎓 Educational Institution Management System (Built on ServiceNow)

A complete solution for managing student admissions, records, and academic performance – built with the power of **ServiceNow App Engine Studio**.

---

## 📌 Features

- 🧾 Student Admission and Enrollment
- 🧑‍🎓 Student Record Management
- 📊 Marks and Result Management
- 📬 Notifications to Students and Faculty
- 📈 Dashboards for Admins to Track Performance
- 🔐 Role-Based Access: Admin, Faculty, Student
- 🧠 Flow Designer for automation of admission approvals and results
- 💼 Record Producers for Admission and Result Entry
- 📱 Workspace UI for efficient access and navigation

---

## 🛠️ Technologies Used

- ServiceNow App Engine Studio
- Flow Designer & Approval Rules
- Dashboards & Reports
- Email Notifications
- ACLs & Role-Based Security
- Workspaces & UI Experiences
- Tables & Data Management
- Record Producers & Catalog Items
